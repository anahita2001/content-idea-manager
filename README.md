# Content Idea Manager

A beginner Python project for managing content ideas.

## Features
- Add new ideas
- Prevent empty and duplicate ideas
- Display saved ideas
- Delete an idea
- Save and load ideas using JSON
- Validate user input

## Technologies
- Python
- JSON

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run: python main.py

- Working with lists and loops
